# 0003 · Mapa: MapLibre con teselas abiertas, sin Google Maps

- **Estado:** aceptada
- **Fecha:** 2026-10-09

## Contexto

El mapa es la vista central. El link va a circular por WhatsApp, así que los picos de carga no se controlan, y el proyecto es open source: cualquiera debería poder forkearlo para otra emergencia sin pedir una API key ni poner una tarjeta.

## Decisión

- **Render:** MapLibre GL JS vía `react-map-gl` (`react-map-gl/maplibre`).
- **Teselas:** OpenFreeMap (gratis, sin key) para partir. Si el tráfico o la disponibilidad lo piden, se pasa a un archivo PMTiles de Chile servido desde Cloud Storage, sin cambiar el código del mapa.
- **Ubicación de una casa:** el vecino marca el punto en el mapa o usa el GPS del celular, y escribe la dirección como texto. **Sin API de geocoding en el MVP.**
- **Agrupación:** el servidor responde por *bounding box* y agrupa los puntos en PostGIS. El cliente nunca recibe todas las casas.

## Por qué no Google Maps

- **Costo impredecible:** desde marzo de 2025 Dynamic Maps trae 10.000 cargas gratis al mes y después cobra por cada 1.000. Un link viral se come eso en horas.
- **Términos de uso:** el contenido del Geocoding API de Google no se puede usar sobre un mapa que no sea de Google. Mezclar su geocoding con MapLibre infringe los términos; usar Google obliga a usar Google para todo.
- **Forks:** cada fork necesitaría su propia cuenta de facturación.

## Consecuencias

- Las direcciones escritas a mano no se validan automáticamente; el punto en el mapa manda.
- Si más adelante hace falta autocompletar direcciones, se evalúa en un ADR nuevo, considerando los términos del proveedor.
